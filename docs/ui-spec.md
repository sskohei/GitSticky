# UI仕様

日本語を標準とし、生成画像・外部フォントのダウンロードは不要。Yu Gothic UI / Meiryo / システムフォントを使用する。6色のパステル付箋、控えめな影、広めの余白で構成する。アイコンだけの操作にもアクセシブルなラベルを付ける。

ホームはブランド、同期、設定、検索、未同期件数、最終同期日時、新規作成と付箋グリッド。付箋にはタイトル（3行で省略）、タグ（2個まで、残りは「+N」）、日付、ピン、未同期ドットを表示する。本文はカードに表示しない。ピン優先、更新日時の降順。検索はタイトル・本文・タグ名をローカル照合する。

検索欄の下に「すべて」「タグなし」と使用中のタグを表示し、タグを複数選択すると、選んだタグがすべて付いたメモのみを表示する。各タグには削除済みを除くメモ件数を表示。キーワード検索とも併用できる。「タグなし」を選ぶと選択タグを解除し、タグを選ぶと「タグなし」を解除する。「すべて」でタグ条件を解除する。使用されなくなった選択中のタグも、解除するまではフィルターに残す。

340px未満で1列、スマートフォンで2列、タブレットで3列、デスクトップで4列、大画面で5列。高さは各ブレークポイントで統一。自由配置・ドラッグは設けない。

編集はデスクトップで幅広の中央モーダル、640px以下で全画面。標準はCodeMirrorとGFMプレビューの同時表示で、760px超は左右、760px以下は上下に分割する。各ペインは独立してスクロールし、入力内容を保存待ち時間なしでプレビューへ反映する。「編集」「分割」「プレビュー」を切り替えられ、表示切替時もエディタを保持して入力やカーソルを失わない。文字数を表示する。

デスクトップのエディタは画面の左右に16px、上下に8pxの余白を残して表示する。タイトル・色選択・保存状態の欄をコンパクトにし、残りの高さを本文に割り当てる。Markdown入力欄は本文ペインの高さ全体を使い、長い本文は入力欄内でスクロールする。

色選択欄の隣にタグ操作を配置する。普段はタグ数と2個までのタグを表示し、「タグ」を押したときだけ編集パネルを開く。パネル内で新しいタグの入力・追加、既存タグ候補からの追加、付いているタグの「×」による解除ができる。日本語IMEの変換確定では追加しない。Escapeはタグパネルだけを閉じ、入力欄のフォーカスをタグボタンへ戻す。タグ変更も500msで自動保存する。タグの階層化・色分け・一括変更は今回の対象外。

生HTMLを描画しない。危険なURLはreact-markdownの既定フィルタで除去し、外部画像は読み込まない。本文・タイトル・ピン・色変更を500msで保存する。閉じる、Ctrl+S、バックグラウンド移行時に保存を要求する。通常のWindows終了は保存完了まで閉じない。保存失敗時にはエディタと入力を残す。

設定はテーマ、自動同期、GitHub接続、リポジトリ、ブランチ。「GitHubで接続」でブラウザを開き、短いコードで承認する。待機、キャンセル、期限切れ、再接続を表示する。GitHub App未設定時は登録が必要と案内し、ローカル利用を継続できる。通常はPATやパスフレーズ入力欄を設けず、旧保管庫がある場合だけ移行欄を表示する。

接続後はリポジトリとブランチを一覧から選び、接続を確認して保存する。設定を開いている間は自動同期を停止し、変更前にローカルメモも新接続先に統合されると案内する。切断してもメモは削除しない。

ライト・ダーク・OS追従を提供。Androidはdvhとsafe-area、adjustResize、CodeMirror行折り返しを使い、ソフトウェアキーボードとタッチ操作に対応する。ボタンは原則44px以上。
