# UI仕様

日本語を標準とし、生成画像・外部フォントのダウンロードは不要。Yu Gothic UI / Meiryo / システムフォントを使用する。6色のパステル付箋、控えめな影、広めの余白で構成する。アイコンだけの操作にもアクセシブルなラベルを付ける。

ホームはブランド、同期、設定、検索、未同期件数、最終同期日時、新規作成と付箋グリッド。付箋にはタイトル（3行で省略）、日付、ピン、未同期ドットだけを表示する。本文はカードに表示しない。ピン優先、更新日時の降順。検索はタイトル・本文をローカル照合する。

340px未満で1列、スマートフォンで2列、タブレットで3列、デスクトップで4列、大画面で5列。高さは各ブレークポイントで統一。自由配置・ドラッグは設けない。

編集はデスクトップで中央モーダル、640px以下で全画面。CodeMirrorの編集とGFMプレビューを切り替える。生HTMLを描画しない。危険なURLはreact-markdownの既定フィルタで除去し、外部画像は読み込まない。本文・タイトル・ピン・色変更を500msで保存する。閉じる、Ctrl+S、バックグラウンド移行時に保存を要求する。通常のWindows終了は保存完了まで閉じない。保存失敗時にはエディタと入力を残す。

設定はテーマ、自動同期、GitHub接続、リポジトリ、ブランチ。「GitHubで接続」でブラウザを開き、短いコードで承認する。待機、キャンセル、期限切れ、再接続を表示する。GitHub App未設定時は登録が必要と案内し、ローカル利用を継続できる。通常はPATやパスフレーズ入力欄を設けず、旧保管庫がある場合だけ移行欄を表示する。

接続後はリポジトリとブランチを一覧から選び、接続を確認して保存する。設定を開いている間は自動同期を停止し、変更前にローカルメモも新接続先に統合されると案内する。切断してもメモは削除しない。

ライト・ダーク・OS追従を提供。Androidはdvhとsafe-area、adjustResize、CodeMirror行折り返しを使い、ソフトウェアキーボードとタッチ操作に対応する。ボタンは原則44px以上。
