# ドキュメント一覧

| 文書                                         | 内容                                                            |
| -------------------------------------------- | --------------------------------------------------------------- |
| [プロジェクト概要](../README.md)             | 機能、利用方法、制約                                            |
| [開発ガイド](development.md)                 | Windows / Androidの準備、コード案内、検証コマンド、トラブル対処 |
| [アーキテクチャ](architecture.md)            | React / Rustの責務、IPC、認証・保存の境界                       |
| [データベース](database.md)                  | SQLiteの構造、移行、更新の整合性                                |

| [GitHub App認証](github-auth.md)             | Appの登録、ビルド設定、接続・認証の移行                         |
| [セキュリティ](security.md)                  | 暗号化、同期の整合性、鍵交換・復旧、制限                        |
| [UI仕様](ui-spec.md)                         | 画面構成、編集・表示・操作                                      |

現在の実装を調べる際は、初期仕様だけで判断せず、上記の各仕様とコードを確認してください。検証記録にある過去の成功は、現在の環境での動作確認とは区別してください。
