# StickyNote v0.1.1

## GitHubの自動同期

- 自動同期は初期設定ではオフです。保存済みの設定に自動同期の項目がない場合も、オフとして読み込みます。
- オンにするには、設定の「GitHubとの同期」で「自動同期を有効にする」にチェックを入れ、「表示・自動同期の設定を保存」を押してください。保存済みの選択は引き継がれます。
- オフの間は、ホーム画面の「同期」から手動で同期できます。

## 更新方法

Windows版の v0.1.0 をお使いの場合は、アプリ内の更新通知から更新できます。新規インストールには、Assets の `StickyNote_0.1.1_x64-setup.exe` を使用してください。

自動テスト、インストーラー生成、更新用署名の検証は GitHub Actions で実行しています。Windowsインストーラーを使った実機での更新と、実際のGitHubを使った端末間同期は未確認です。
