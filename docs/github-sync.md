# GitHub同期

`GitHub` と `LocalDatabase` をインターフェースにし、同期エンジンをUI・通信・DB実装から分離する。実アプリではRustコマンド、テストではインメモリアダプタを使用する。

1. 同期中のPromiseを共有し、多重実行を防ぐ。開いているエディタを先に保存する。
2. Branch APIで対象ブランチの存在とtree SHAを確認する。
3. 再帰Git Trees APIで完全な一覧を取得する。truncatedの場合は同期を中止する。暗号化した管理ファイルの一覧・世代と照合し、無断変更や確認済み世代からの巻き戻しを拒否する。
4. `notes/{UUID}.md` のblobをSHAで取得し、UTF-8とYAMLを検証する。一覧や通信取得失敗があれば削除判定前に中断する。不正MarkdownのIDは更新・削除しない。
5. 各IDについて現在のローカルrevision、接続先ごとの最終同期状態、リモートSHAを比較する。
6. ローカル更新・削除と暗号化した管理ファイルをGit Database APIの単一tree・commitで更新し、非強制のref更新で反映する。成功したrevisionとSHAのみ確認する。

| 状況                           | 処理                                               |
| ------------------------------ | -------------------------------------------------- |
| ローカルのみ変更               | 確認済みSHAを照合し、単一commitで更新・削除        |
| リモートのみ変更               | CASでダウンロード。updatedAtはそのまま             |
| 同一の内容・メタデータ         | SHAを更新して同期済みにする                        |
| 異なる同時変更                 | 新UUIDの競合コピーを保存し、元IDにリモート版を反映 |
| リモート削除、ローカル未編集   | ローカルにも削除を反映                             |
| リモート削除、ローカル編集済み | ローカル本文を新UUIDの競合コピーに保護             |
| ローカル削除、リモート変更済み | 削除せずリモート版を復元、競合を通知               |

競合コピーと基準更新をトランザクションにし、次回同じ競合でコピーが増え続けないようにする。アップロード途中の追加入力はdirtyのまま維持する。HTTP 409 / 422は一覧と対象blobを再取得し、最大3回まで再判定する。変更リクエストはネットワークエラー時に無条件に再送しない。応答喪失後は次回同期でリモート内容と照合する。

GETは30秒タイムアウト、接続は10秒、ネットワークエラー・5xxに400ms/800msのバックオフ（最大3試行）。401、403、404、競合、レート制限を型付きエラーで区別する。Retry-After秒とX-RateLimit-Resetの遅い方を尊重し、自動同期を抑止する。秘密情報・本文をログに出さない。

保存形式はUTF-8、YAML Front Matterの schemaVersion / id / title / color / pinned / createdAt / updatedAt、続いてMarkdown本文。タグなしは従来の `schemaVersion: 1`、タグ付きは `schemaVersion: 2` と `tags` の文字列配列を出力する。v1の読み込みはタグなしとして扱い、v2ではタグ配列を必須として検証する。v1にtagsが混在したファイルは拒否する。YAMLライブラリで引用・改行をエスケープし、重複キー・alias・不正型・ID不一致を拒否する。管理対象外ファイルは変更しない。

タグは本文と同じ同期単位に含め、タグだけの変更も差分として検出する。順番とASCII英字の大小文字だけの差は同じタグ集合とみなす。同時変更時は既存の競合コピー方式で両方のタグ集合を保護する。

旧版はv2を未対応形式として扱い、該当メモの読み書き・削除を中止するため、タグ付きメモをタグなしで上書きしない。タグ機能の利用開始時は同期するすべての端末を更新する。最後のタグを外したメモはv1で保存する。ローカルDBのマイグレーション後の旧版へのダウングレードは対象外。

起動・フォアグラウンド復帰・オンライン復帰・ローカル編集完了後15秒で自動同期する。起動時はOS保護領域から認証を復元する。期限切れはRustが更新し、再承認が必要な場合はローカル編集を維持して接続を案内する。自動同期は設定から無効化でき、手動同期は常に要求できる。

## 暗号化と公開範囲

同期先は非公開リポジトリに限定する。送信前にRustでMarkdown全体をAES-256-GCM暗号化し、schemaVersion 3のJSONとして保存する。受信後にRustが復号してから、従来のFront Matter解析・差分判定を行う。既存の平文メモも同期時に暗号化し、移行完了後は平文へのダウングレードを拒否する。暗号鍵は端末間で同じものを登録する。旧バージョンとの互換性・過去のGit履歴・鍵の紛失については [security.md](security.md) を参照。
