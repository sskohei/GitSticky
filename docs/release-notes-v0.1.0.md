# StickyNote v0.1.0

GitHubと同期できる、日本語の付箋メモアプリです。Windows 10 / 11のx64版に対応します。

## 主な機能

- Markdownの編集とプレビュー、500msの自動保存。
- メモの色分け、ピン留め、タグ、本文・タイトル検索。
- オフラインでの作成・編集と、再起動後のデータ保持。
- 非公開GitHubリポジトリとの同期、競合時のコピー保護。
- メモの暗号化、Windows DPAPIによる認証情報と鍵の保護。
- Light / Dark / Systemテーマ。
- 署名を検証するアプリ内更新。更新は通知のボタンから開始します。

## インストール

ReleaseのAssetsから `StickyNote_0.1.0_x64-setup.exe` をダウンロードして実行してください。日本語・英語を選択でき、現在のWindowsユーザー用にインストールします。WebView2がない場合は自動でダウンロードするため、インターネット接続が必要です。

GitHub同期にはGitHubでの認可、非公開リポジトリの選択、同期用暗号鍵の登録が必要です。暗号鍵は安全な場所に保管し、別端末でも同じ鍵を登録してください。

インストーラーにはWindowsの発行元署名を付けていないため、Windowsの警告が表示される場合があります。アプリ内更新用の署名は付けており、更新ファイルの改ざんとバージョンを検証します。

## 既知の制約

- 画像添付、自由配置、リアルタイム共同編集には対応していません。
- 同期の競合は自動マージせず、ローカル側を競合コピーとして保持します。
- 全メモを取得して同期するため、大規模なリポジトリには向きません。
- 自動保存が終わる前の強制終了では、直前の入力を保持できない場合があります。
- 更新機能を持たない開発版からの移行には、インストーラーでの手動更新が必要です。

データの保管と暗号化の詳細は [セキュリティの説明](https://github.com/sskohei/GitSticky/blob/main/docs/security.md) を参照してください。
